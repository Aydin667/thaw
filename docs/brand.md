# Thaw — Brand Identity

## Name

**Thaw** — the dev bag is never frozen behind a cliff; it *thaws* (melts) gradually from the token's first second. The name is the mechanic: a slow, visible, unstoppable melt instead of a locked block with a surprise unlock date.

Shortlisted against: Drip, Trickle, Melt, Glacier, Faucet, Steady, Even, Flow, Thaw. **Thaw** won: short, pronounceable, crypto-legible, and it carries the exact product image (frozen → melting) that differentiates it from lock-based launchpads. Ticker: `$THAW`.

## Coin

- **Coin name:** Thaw
- **Ticker:** `$THAW`

Launched through Thaw itself with a Glacial melt — the platform dogfooding its slowest schedule is the launch story.

## Tagline

**"The dev bag melts in public."**

Secondary: "Capped, no cliff, on-chain from second zero." / "No unlock walls. Just a slow, public drip."

## Voice
Same family as the terminal aesthetic: technical, dry, exact. State the guarantee and the non-guarantee. The honesty is the brand.

## Visual identity

**Aesthetic:** phosphor/terminal, shared with the sibling product, but the signal color is **icy cyan** instead of green — cold, "frozen thawing" connotation. Near-black CRT base, cyan primary, amber caution, pixel-art iconography, sparing scanlines.

| Token | Hex | Use |
|---|---|---|
| `bg` | `#0A0A0C` | page background |

(In code the CSS token is still named `--color-green` for component-class reuse; its value is the cyan above.)

### Typography
- **Display / logo:** Silkscreen (pixel).
- **UI / body:** Space Grotesk.
- **Data / code:** JetBrains Mono.

### Logo
Wordmark `THAW` in Silkscreen, split two-tone: `TH` in text-white, `AW` in cyan. Mark: a **pixel ice block with a melting, dripping bottom edge and a droplet falling below** — cyan with a frost highlight. Reads at avatar size.

### Mascot
None — the melting-ice mark carries the identity.

### UI language
Identical system to the sibling product (1px borders, 2px radius, no shadows, terminal prompts, `[ OK ]`/`[FAIL]` status cells, 120–180ms transitions, blinking cursor). The success animation is a "≈ THAWING" stamp instead of a lock stamp.
